# Scenes Folder

This is now the canonical scene workspace for the project.

If you want to pull out and edit a single scene, use one of these folders:

- `scenes/stash/`
  - current first playable scene after a run starts
- `scenes/tavern/`
- `scenes/poker/`
- `scenes/extraction/`
- `scenes/menu/` for the title/start scene

Each scene folder is intended to hold:

- `index.js`
  - scene rendering logic
- `style.css`
  - scene-local visual rules
- `README.md`
  - editing notes and ownership guidance
