# Audio Layout

Put generated music in these folders:

- `assets/audio/bgm/`
- `assets/audio/sfx/`

Recommended BGM filenames:

- `menu-theme.ogg`
- `stash-loop.ogg`
- `tavern-floor.ogg`
- `table-pressure.ogg`
- `summary-success.ogg`
- `summary-failure.ogg`

Preferred format:

- `ogg` for in-game playback on web
- keep a matching `mp3` export outside the repo if you want easy review or sharing

Loop guidance:

- aim for 60-90 second seamless loops
- avoid large cymbal crashes or sudden endings
- keep decision-heavy scenes sparse so text and actions stay readable
