# 首桌规则迁移记录

更新：2026-09-08。

## 本轮交付

货运桌独立试玩：入座后点击“开始牌局”，每席 60 筹码，盲注 10 / 20，最多两手。支持弃牌、过牌、跟注、指定加注总额、全押、自动对手行动、翻牌／转牌／河牌、摊牌分账、下一手及桌后离座。

牌桌为独立试玩，不扣减长期资产，不写入浏览器存档，也不代表搜索、道具、风声和撤离已经完成迁移。桌级随机种子独立生成；局级随机进度和断点存档尚未迁移。

## 实现边界

- `rules/table.gd`：同步、独立于场景的牌桌状态和资金变化，动作需要匹配行动者、合法动作与状态版本。
- `rules/opponent.gd`：迁移原有性格修正与概率决策，不调用网络服务，只使用自身手牌及公共信息。
- `scripts/table_hud.gd`：接收过滤后的公开状态，显示动作、金额、日志和结算。
- `scripts/world.gd`：负责入座、控制器调用、暂停、行动间隔与三维牌面表现；不直接修改筹码。
- `rules/content.json`：当前四套牌桌及八位对手的迁移快照；只有货运桌已接入场景。通过 `tests/sync_content.mjs` 显式刷新，避免维护者误以为会自动同步网页数据。

## 相对旧实现明确修正的行为

1. 弃牌获胜后，只要至少两位玩家仍有筹码且未达到手数上限，就继续下一手；判断资金人数时不排除本手已经弃牌的人。
2. 发牌名单在扣盲注前保存，盲注全押者仍获得两张手牌，并有资格参与摊牌。
3. 仅剩两人时，庄家下小盲且翻牌前先行动；翻牌后另一位先行动。
4. 其他未弃牌者均已全押且唯一有筹码者无需补跟注时，不要求无意义的过牌／下注，直接继续公共牌。
5. 对手概率计算不使用他人的未公开弃牌；全押但未弃牌的对手仍计入竞争人数。

保留当前货运桌“首次主动加注少付 10”的既有计费行为，以及现有平分底池余数按座位先后发放的约定；不是同时重设计规则。

上述修正只作用于新 Godot 模块，没有修改网页原版。其余常规动作使用既有网页实现生成固定快照作对照。
