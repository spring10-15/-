# 3D 首桌资金与撤离闭环

更新：2026-09-08。

## 当前可操作流程

1. 藏匿点对准右侧门按 E，查看出发金额，再点“带钱出发”。金库初始 1,200，每次带出最多 300，最低 120。
2. 在酒馆牌桌前按 E 入座。开始时从随身现金扣 60；未开局离座不扣钱。
3. 完成最多两手后离桌，将实际剩余筹码返还随身现金。本局不能重复买入货运桌。
4. 查看入口门旁的白色“EXIT / 出口告示”。对准门按 E，预览费用和到账金额；确认支付后返回藏匿点。
5. 上局结果显示在藏匿点左上角，可以再次带钱出发。资金不足最低门槛时，明确点击“重置试玩资金”才能恢复到 1,200。

所有资金仅保留在本次程序运行中。关闭程序会丢失进度；不读取或改写网页原版存档。

## 与网页原版的关系

- 初始金库、标准带出金额、买入、入桌风声及烟雾酒馆费率通过 `tests/sync_content.mjs` 从 `src/data.js` 生成快照。
- 资金转移对应 `src/game.js` 的 `startRun`、`enterTable`、`concludeTable`、`attemptExtraction`。
- 普通撤离费用为 `24 + floor(随身现金 × 0.12)`。风声为 5 时另加 45，达到 6 时封锁；资金不足不能使用。当前单桌只增加 1 点风声，完整压力推进尚未接入。
- 例：带出 300，首桌亏完 60，随身剩 240；撤离费 52，到账 188，金库从 1,200 变为 1,088，本局净变化 -112。
- 出口线索暂由固定的门旁告示提供，不消耗行动点。这是灰盒交互入口，**不是原版搜索事件的完整迁移**。
- 原版余额过低会自动恢复默认档；3D 试玩改为显式重置按钮，避免自动补钱掩盖损益。
- 胜利物品奖励、抵押、完整搜索与库存、第二桌、其它路线、局级随机序列和存档均未迁移，不应把此闭环视为完整游戏规则验收。

## 实现和验证

`rules/run.gd` 统一持有资金、当前牌桌、已完成牌桌和撤离状态；场景只提交动作并显示结果。版本检查拒绝过期确认，且只有内部持有的已结束牌桌可以返还筹码。买入、离桌和撤离均不能重复执行。

- `run_test.gd`：640 项检查，含 30 组固定牌局的出发到撤离资金守恒、重复请求、最低带出金额、费用不足与封锁边界。
- `table_integration.gd`：58 项检查，通过真实 HUD 按钮和射线交互完成两手、离桌、发现出口、撤离到账，并核对重复输入不增加资金。
- `smoke.gd`：26 项探索及物理交互检查。
- `capture_table.gd`：实际 Metal 渲染，新增 `output/3d/run-departure.png`、`run-extraction.png`、`run-return.png`。

场景仍为粗模，未完成最终美术、长时间稳定性或独立安装包验收。
